What we know vs. what we don't

✓ Known (sourced)

  • Project 2026 is on the official group as “Project 2026 (2026) — To be announced”. Group
  • Founder Bryce_TBS lists it first under Current Projects. Profile
  • An official Project 2026 Testing Server has existed since 7 Dec 2025, for “Tableboard Studios's newest game”, under NDA. Roblox API
  • A P26 Building Systems Development place has existed since 28 Aug 2026. Roblox API
  • Both places were updated on 20 Oct 2026. Roblox API
  • Every Tableboard game has had a testing server in the same group: Cruise Line Simulator: Classic (Jun 2021), A New Era (May 2022, about 7 months before that game went up), and Cruise Ship Simulator (21 Apr 2024, the same day as the game). Dev group games

? Not known yet

  • What kind of game it is. The testing server only calls it the studio's “newest game”. The studio describes itself as making “maritime games”, but no source says Project 2026 is a ship game.
  • A release date. The listing only says “To be announced”.
  • Whether testing is being finalized. Nothing public says so.
  • Features. No trailer, screenshots or feature list are public. The testing server's NDA says nothing may be posted without permission.
  • The final name. “Project 2026” looks like a codename. The dev group's own description lists “Project 2027 (Release: TBA)” as a work in progress. That could be a typo or a separate project; no source says which.

FAQ

Is Project 2026 real?

Yes. It's listed on the official Tableboard Studios Roblox group as “Project 2026 (2026) — To be announced”, and founder Bryce_TBS lists it as a current project.

Why does this site say testing is YES?

The site owner (Zephplays134) confirms it. The strongest public evidence is a “Project 2026 Testing Server” on Roblox, which describes itself as the official testing server for the studio's newest game. It's listed in the studio's invite-only development group, which Bryce_TBS owns. The studio hasn't announced testing publicly.

Does this page update itself?

Yes, in two ways. A GitHub bot checks Roblox every 6 hours (the test places' “last updated” dates, new places in either studio group, the group descriptions and the founder's current projects) and adds an “Auto-detected” entry to the updates when something changes. And while you have the page open, it re-checks Roblox every 2 minutes and tells you if anything moved. The three YES/NO answers never change automatically: if the bot sees something big, like a public Project 2026 game, it shows an attention flag and the site owner decides.

Can I join the testing server?

No public way exists. It sits in an invite-only group, and its description says the game and its contents are under NDA, so nothing may be posted publicly without the development team's permission. Please don't pester the developers for access.

Are they finalizing testing?

Not confirmed. Nothing public says testing is in its final stage. The test places were still being updated on 20 Oct 2026.

When does Project 2026 come out?

No date has been announced. The name points to 2026, but the official listing only says “To be announced”.

Is it a cruise ship game, or Cruise Ship Simulator 2?

Unknown. The studio makes maritime games and Project 2026 is listed beside Cruise Ship Simulator, but no source says what Project 2026 is. Anything else is a guess.

What is “P26 Building Systems Development”?

A second Project 2026 place in the studio's development group, created 28 Aug 2026. Its name suggests work on building systems. It has no public description, so the details are unknown.

Where do official announcements show up?

Usually on the Roblox group, the studio's Discord (“Communications Server”), TikTok (@tableboard_studios) and X (@TBStudiosRBLX). Cruise Ship Simulator updates have been teased on TikTok before they shipped.

Is this site official?

No. It's a fan-run tracker by Zephplays134 and isn't affiliated with Tableboard Studios or Roblox. Every fact links to its source.

How does the live data work?

When you open the page, it asks Roblox's public API (through a public mirror) for Cruise Ship Simulator's visits, favorites, players and the group's member count, plus the test places' “last updated” dates. If that fails, it shows the numbers read on 28 Oct 2026.

What does this site remember about me?

Only what's listed under “Your saved data” below: your theme, your update filter, when you last visited and the stats from that visit. It's stored in your own browser (localStorage). Nothing is sent anywhere, and there are no cookies or trackers.
