FAQ

What is Project 2026?

An upcoming Roblox game from Tableboard Studios, the studio behind Cruise Ship Simulator and the Cruise Line Simulator games. Its official listing reads “Project 2026 (2026) — To be announced”. The real name, genre and features haven't been revealed.

Why does it say YES to internal testing?

The site owner, Zephplays134, confirms it. It's backed by a third-party tracker that lists a private “Project 2026 Testing Server” and a “P26 Building Systems Development” place owned by the studio's founder. There's no official studio post about testing yet.

Are they finalizing testing?

Not confirmed. Nothing public says testing is in its final stage, so the badge stays on NOT CONFIRMED until there's evidence either way.

When does Project 2026 come out?

No release date has been announced. The name suggests 2026, and the official group lists it as a 2026 game.

Is this an official Tableboard Studios site?

No. It's a fan-run tracker. Every fact links to where it came from in the Sources section.

How is this page updated?

All answers and updates live in data/status.json in the GitHub repo. Edit that one file and the page updates itself.
